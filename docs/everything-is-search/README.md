# Everything Is Search — working documents

Status: discovery draft, 2026-10-13. This is a record of an emerging idea, not an agreed theory or implementation specification.

The immediate task is to capture the creator's intuition and make it discussable. The eventual outputs are a progressive interactive website and a documentary-style film, using Concept Space as a visual and technical reference. Neither output is being built yet.

For an independent continuation, start with [the handoff](HANDOFF.md).

Read in this order:

1. [Vision and central questions](vision.md) — what the creator has said, what remains unresolved, and proposed interpretations.
2. [Visual language](visual-language.md) — possible space, reachable space, exploration, persistence, and what the marks should mean.
3. [Website and film journey](journey.md) — a provisional learning sequence and candidate examples.
4. [Discovery process](discovery.md) — how to refine the idea together, with decisions and questions recorded explicitly.

## Current agreements

- “Everything is search” is a working lens or not-quite-theory to explore, not an established universal claim.
- Search need not be *for* a predetermined thing. Exploration is central.
- What it means for things to persist remains deliberately unresolved and may differ fundamentally by example.
- Introduce the visual language progressively, starting in 2D and moving to 3D. A brief line-based introduction is optional if useful.
- Keep the visual ambition of Concept Space: large, dynamic, beautiful scenes with pertinent narrative.
- Build understanding through modules, from simple examples toward more complex ones.
- Explore how constraints, choices, and other conditions affect what can be reached and what actually happens.
- Ultimately create both a website and a documentary-style video. The film should reuse visualizations developed for the website; `~/Work/motion-mania` is a candidate production tool.
- For now, document and refine. No site rewrite, repository rename, deployment, video production, or research conclusions are implied by this draft.

## How to read these documents

“Creator direction” records the user's intent. “Proposal” marks assistant contributions awaiting discussion. “Open” identifies unresolved meaning. Candidate examples are invitations to investigate, not claims that all the underlying mechanisms are equivalent. No literature review has yet been performed for this new direction.

The existing application and its feedback fixes are included in the handoff baseline. These documents can evolve independently while the new direction becomes clearer.

## Latest clarification

The creator's anchor examples are **biological evolution, human cultural/societal evolution at micro and macro levels, and neural-network training**. These now guide conceptual development; the simple opening examples remain proposed teaching devices.

The **adjacent possible** and **tangible local examples that progressively zoom outward** are now central directions. The creator connects the phrase to their late friend Jim Rutt. The documents preserve that association while leaving public attribution and treatment undecided.
